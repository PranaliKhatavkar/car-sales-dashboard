# car-sales-dashboard
Dashboard for analysing car sales
The goal of an interactive Power BI project “Thermal Power Plant Efficiency Analysis Dashboard” is to analyze and monitor the operational performance of thermal power plants. It visualizes key performance indicators. The dashboard compares plant performance and identifies operational trends. This project demonstrates how Power BI can transform raw plant data into meaningful insights, supporting better decision-making and efficient performance monitoring.
Done data preprocessing, created DAX measures and created dashboard using different KPI, charts etc and analysed the performance
